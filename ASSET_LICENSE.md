# Art, audio, and other assets

The repository's MIT license applies to original software code and documentation contributed under that license. It **does not automatically relicense** third-party assets or externally sourced artwork, music, sound effects, fonts, or trademarks.

Before importing or publishing asset files:

1. Record each asset's origin and original author.
2. Confirm whether redistribution, modification, and public hosting are permitted.
3. Keep applicable license notices and attribution.
4. Replace unlicensed or unclear-origin assets before making the repository public.

Maintain an asset inventory in this document or a separate manifest as the project grows.
